# 拆解系統思考｜免費開源筆記

這是 YouTube 頻道 [@GopachStudyNotes](https://www.youtube.com/@GopachStudyNotes) 系列 Shorts「**拆解系統思考**」的配套筆記。

影片只有幾十秒到一分多鐘，放不下完整的出處、頁碼和原文。這個 repo 把每一集沒時間講完的東西補齊：核心觀念、白話解釋、圖、引用的原文（附意譯）、我們自己的推導，以及每一筆資料的來源。

> 這個系列的目標讀者：**完全沒學過系統思考的人**。不需要任何背景知識，從第 1 集依序看到第 11 集就可以。

## 這個系列在講什麼

系統思考的核心是：**看整體、看關係、看回饋，而不是只盯著單一事件**。

很多問題「越努力越糟」、「同樣的事一再發生」、「調整總是過頭」，常常不是人的問題，而是問題背後的結構造成的。這個系列用 11 集，從它的源頭，一路講到畫圖、找問題、找槓桿點，最後談到 AI agent 時代為什麼更需要它。

## 怎麼使用這份筆記

1. **先看影片，再看筆記**：影片負責讓你抓到重點，筆記負責補細節和出處。
2. **想自己查原文**：每集最後的「來源」都列了作者、作品、年份，以及我們引用的位置（頁碼或章節）。
3. **想分辨「原作者說的」和「我們自己的想法」**：筆記裡有兩種標記：
   - **意譯**：英文原文旁邊的中文，是我們的翻譯，不是官方譯文。
   - **推導**：我們自己的歸納、編排或舉例，不是任何作者的原話。
4. **發現錯誤或有更好的來源**：歡迎開 Issue 或 Pull Request。

## 來源原則

- **引文只用逐字核對過的**：每句引文都對照過原文（書、論文、官方網頁、逐字稿）。沒有核對過的，我們只做轉述，不加引號。
- **英文引文一律附意譯**，並標出作者、作品、年份與位置。
- **以一手來源為主**：作者本人的文章、書、論文、官方逐字稿。筆記不以維基百科為依據。（第 1 集影片當時標示了維基百科，已在該集筆記的「影片當時引用」如實列出，並補上一手來源。）
- **假設例就說是假設例**：影片裡的加班、便當店、待辦清單、救火團隊，都是我們為了說明結構編的例子，不是真實個案。
- **黃仁勳的英文原話**來自 YouTube 自動字幕（有些來自 Lex Fridman 官方人工逐字稿），可能有口誤或標點差異，我們已標明；引用前請以影片音訊為準。
- 本頻道與文中提到的人物、公司、出版社**沒有任何關聯**。
- 術語：中文統一寫「環路」（reinforcing loop＝增強環路、balancing loop＝調節環路）；agent、subagent、multi-agent、token 保留英文。
